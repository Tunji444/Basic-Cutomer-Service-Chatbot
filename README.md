# Simple ShopAssist starter

A small Python practice project for a fictional online shop.

## Files
- `starter.py` — chatbot starter code with TODOs.
- `README.md` — these instructions.

## Run it
Open a terminal in this folder and run:

```bash
python starter.py
```

## Your tasks
1. Implement `find_order(order_id)`.
2. Implement `answer_question(message)`.
3. Update `main()` to recognise order questions and look up an order.
4. Try questions like:
   - How long does delivery take?
   - Can I get a refund?
   - How do returns work?
   - Where is my order?
5. Add one FAQ and one fictional order of your own.

All sample data is fictional. This is only a practice chatbot; it does not connect to a real shop or process payments.
